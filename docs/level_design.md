# 关卡设计与技术实现 (Level Design & Canvas Tech)

用户担心：*纯 Canvas 能实现“轨道站”和“外星基地”这样宏大的场景吗？*
回答：**完全可以。** 我们采用经典的 **2D 视差滚动 (Parallax Scrolling)** 和 **组合图层 (Compositing)** 技术。

## Chapter 1: 地球轨道 (Earth Orbit)
### 视觉设计
*   **背景**: 并非 3D 星球，而是一张巨大的、无缝连接的**地球弧线图片**。
*   **动态**: 这张背景图以极慢的速度向下滚动，模拟战机在轨道上高速飞行的相对运动。
*   **Canvas 实现**: `ctx.drawImage(earthBg, 0, scrollY, width, height)`。

### Boss: 轨道防御平台 (Orbital Platform)
*   **设计**: 这是一个**“多部件组合 Boss”** (Multi-Part Boss)。
*   **结构**:
    1.  **Main Core (核心)**: 位于屏幕上方正中，血量最高。
    2.  **Left/Right Wing (左右翼)**: 两个独立的炮台对象，跟随核心移动。
*   **Canvas 实现**: 我们不需要绘制复杂的 3D 模型，只需要加载 3 张高清 PNG 图片（核心+左翼+右翼），在 `render()` 中计算好相对坐标分别绘制。
*   **轨道炮特效**: 使用 `ctx.moveTo/lineTo` + `shadowBlur` 绘制一条高亮的白色直线，瞬间出现并消失，模拟激光束。

## Chapter 2: 月球背面 (Dark Side of Moon)
### 视觉设计
*   **背景**: 使用一张**可平铺 (Tileable)** 的灰色陨石坑纹理。
*   **外星基地**: 基地不是背景的一部分，而是**“地表物件层” (Ground Layer)**。我们通过在背景之上、战机之下，绘制一些“建筑物图片”，让它们随背景一起快速滚动，产生“飞越基地”的纵深感。

## Chapter 3: 火星风暴 (Mars Storm)
### 视觉特效 (VFX)
*   **沙尘暴**: 这不需要复杂的粒子模拟。
*   **Canvas 实现**:
    1.  创建一个半透明的橙色图层 `RGBA(255, 100, 0, 0.3)` 覆盖全屏。
    2.  在图层上绘制一些快速流动的白色噪点或云雾图片（Cloud Texture）。
    3.  通过 `globalAlpha` 动态调整透明度，模拟风暴的强弱变化。

---
**技术总结**:
我们不需要 3D 引擎。所有的宏大场景都是通过 **“图片层叠” (Layering)** 和 **“相对运动” (Relative Motion)** 欺骗眼睛实现的。这是 2D 游戏开发（如《雷电》、《打击者1945》）的标准做法，在微信小游戏中运行毫无压力。
