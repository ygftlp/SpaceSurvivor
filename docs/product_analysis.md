# Space Survivor - 产品分析与设计文档

## 1. 核心玩点 (Game Loop & Fun Factor)
*   **Roguelite 技能构建**: 这不仅仅是躲避弹幕。我们引入了“局内成长”机制。玩家每次升级都能在随机技能（如“多重射击”、“僚机支援”、“能量护盾”）中进行三选一。每一局的游戏体验都是独一无二的，这种“构建Build”的策略性是游戏最好玩的地方。
*   **极限闪避的爽快感**: 面对满屏绚丽的弹幕，通过精准的微操（Joystick）在缝隙中求生，这种“刀尖上跳舞”的紧张感和成功后的成就感是STG（射击游戏）的核心魅力。
*   **高保真战机驾驶**: 区别于市面上常见的卡通/Q版画风，我们提供 J20、F22、Su57 等高精度建模的真实战机，配合动态星空背景，给玩家带来沉浸式的王牌飞行员体验。

## 2. 用户粘性 (Retention Strategy)
*   **机库收集欲望**: 即使一局游戏结束了，玩家的目标感依然存在。通过战斗获取金币，解锁梦寐以求的顶级战机（如 J20 威龙）。这种“收集+养成”的长期目标是留存的关键。
*   **数值成长反馈**: 局外升级系统（提升基础攻击、血量上限）让玩家直观地感受到自己在变强。昨天打不过的关卡，今天升级装备后就能碾压，这种正向反馈极具粘性。
*   **社交与竞争**: 设置无尽模式排行榜。利用微信小游戏的社交属性，让玩家看到好友的分数，“超过他”往往是重复游玩的强动力。

## 3. 产品定位 (Product Positioning)
*   **赛道选择**: 微信小游戏 / 轻度休闲。
*   **差异化风格**: **硬核科幻 (Hardcore Sci-Fi)**。目前小游戏平台多为轻松搞怪风格，一款画面精美、手感扎实、题材硬朗的空战游戏能迅速抓住军迷和追求品质感的男性用户群体。
*   **目标受众**: 25-40岁男性，STG爱好者，以及需要“短时间解压”的上班族。

## 4. 产品价值 (Product Value)
*   **情绪价值 (解压)**: 极短时间内的压力释放。看着满屏敌人被自己的弹幕消灭（割草感），配合爆炸的视觉特效，能提供极强的多巴胺分泌。
*   **心流体验**: 游戏操作门槛低（只需控制移动），但上限高。玩家很容易进入忘我的“心流”状态，暂时忘却现实烦恼。
*   **碎片化娱乐**: 随时随地，即开即玩，一局3-5分钟，完美契合现代人的碎片时间。
