# 社交与竞技设计 (Social & Competition)

用户提问：*“玩家之间的比拼是啥？”*

《星际幸存者》作为一个微信小游戏，虽然核心是 PVE（打怪），但人与人之间的**“间接竞争”**是维持热度的关键。

## 1. 好友排行榜 (Leaderboard)
最直接的比拼。

*   **无尽模式榜**: 比拼谁活得更久。
    *   *Ranking*: 1. 张三 (22分10秒) 2. 李四 (18分30秒) ...
    *   *展示*: 每周一结算，第一名获得【王牌飞行员】限时头像框。
*   **关卡进度榜**: 比拼谁推图最快。
    *   *Ranking*: 1. 张三 (通关 3-10) 2. 李四 (通关 2-5)

## 2. 影子挑战 (Ghost Challenge)
异步竞技机制。

*   **机制**: 
    1.  当你在第 5 分钟阵亡时，你会在那个位置留下一个**“战机残骸”**。
    2.  你的好友在玩的时候，会路过你的残骸。
    3.  系统提示：`发现好友 [李四] 的残骸，击败围攻他的敌人可获得额外奖励！`
*   **心理**: “李四死在这里，但我冲过去了，说明我比他强。”

## 3. 战报分享 (Battle Report)
晒图装逼。

*   **结算卡片**: 生成一张酷炫的图片，列出你的战绩：
    *   *击杀数*: 12,450
    *   *最高连击*: 999
    *   *称号*: 【星际主宰】
    *   *评语*: “你的操作超越了 99% 的飞行员！”
*   **一键转发**: 直接发到微信群，点击的人可以领取少量金币（诱导点击）。

## 4. 军衔系统 (Rank Title)
身份象征。

*   **等级**: 
    Newbie (新兵) -> Ace (王牌) -> Top Gun (枪王) -> Legend (传奇) -> Marshal (元帅)
*   **外显**: 高级军衔的飞机拥有特殊的**尾焰颜色**（如元帅是紫焰），在联机大厅或排行榜上极其显眼。

---
**总结**:
虽然我们不能做实时 PVP（技术成本高且体验差），但通过**排行榜**、**残骸挑战**和**炫耀分享**，依然能激起玩家强烈的胜负欲。
