# 局内技能设计 (Roguelite Skills)

在《星际幸存者》中，通过收集蓝色能量球升级，玩家可以在 3 个随机选项中选择一项。

## 1. 攻击系 (Offense - Red)
核心输出手段，决定了“清怪效率”。

*   **多重射击 (Multi-Shot)**: 增加主武器的发射数量。
    *   *Lv.1*: +1 发子弹 (变为双发 V 行)。
    *   *Lv.5*: +4 发子弹 (变为扇形弹幕)。
*   **急速冷却 (Rapid Fire)**: 增加 15% 射速。配合“能量机制”，即使过热也能更快恢复？不，应该减少过热惩罚。
*   **穿甲弹 (Piercing)**: 子弹可以穿透 1 个敌人。
*   **弹射 (Bounce)**: 子弹命中后弹射到附近的敌人。

## 2. 战术/副武器系 (Tactical - Yellow)
独立于主炮的自动攻击手段。

*   **浮游炮 (Drone)**: 召唤一个悬浮在机身侧后方的无人机，自动攻击最近敌人。
*   **制导飞弹 (Missile)**: 每隔 3秒 发射一枚追踪导弹，造成范围爆炸。
*   **特斯拉电圈 (Tesla Coil)**: 战机周围产生电环，对近身敌人造成持续伤害（防撞脸神器）。

## 3. 防御/辅助系 (Utility - Blue)
活着才有输出。

*   **能量护盾 (Energy Shield)**: 产生一个能抵挡 1 次伤害的护盾。护盾破碎后，需要 10秒 充能。
*   **磁力场 (Magnet)**: 增加 50% 拾取范围。不用再为了捡球而冲进怪堆找死。
*   **聚变引擎 (Engine)**: 增加 10% 移速。

## 4. 进化机制 (Evolution)
为了增加长线策略，某些技能满级后可以**“超进化”**：

*   **【天罚激光】 (Heaven's Laser)**:
    *   *配方*: [多重射击 Lv.5] + [透镜 (被动)]
    *   *效果*: 原本的实弹变为高能激光，瞬间穿透屏幕上所有直线敌人。
*   **【万剑归宗】 (Blade Storm)**:
    *   *配方*: [浮游炮 Lv.5] + [磁力场]
    *   *效果*: 浮游炮数量翻倍，且围绕战机高速旋转，形成绞肉机力场。

---
**设计意图**:
前期玩家通常优先点“多重射击”保命；中期需要“磁力场”快速发育；后期必须合成“超进化武器”才能击败 BOSS。
