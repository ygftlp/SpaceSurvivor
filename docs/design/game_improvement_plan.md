# Operation: Adrenaline (Game Improvement Plan)

## Problem Diagnosis
The user reported the game feels "boring". Based on the current build, we identified three potential causes:
1.  **Low Impact**: Shooting enemies feels "floaty". No weight, no crunch.
2.  **Flat Progression**: Getting +10% Speed is mathematically good but emotionally dull.
3.  **Monotony**: Endless waves of drones can get repetitive without distinct peaks.

## Proposed Solutions

### 1. The "Juice" Update (Visual & Feedback)
*Goal: Make every interaction feel satisfying.*
*   **Screen Shake**: The screen should shudder when a bomb explodes or user takes damage.
*   **Hit Stop**: A micro-pause (20ms) when killing a heavy enemy to emphasize impact.
*   **Particle Systems**:
    *   **Explosions**: Debris and fire sparks instead of just "poof".
    *   **Trails**: Missiles/Fighters leave smoke trails.
*   **Damage Numbers**: Pop-up numbers to show critical hits.

### 2. Roguelike 2.0 (Synergy & Crazy Tech)
*Goal: Make players feel like "Mad Scientists".*
*   **Ricochet**: Bullets bounce off walls/enemies.
*   **Chain Lightning**: Hits connect to nearby enemies.
*   **Execution**: Enemies below 20% HP explode instantly.
*   **Multicast**: Chance to fire your weapon 3 times at once.

### 3. The "Ace Pilot" Momentum
*Goal: Reward skill, punish passivity.*
*   **Combo System**: Kill enemies quickly to build a "Heat Gauge".
    *   *High Heat* = Faster Fire Rate + Glowing Weapons.
    *   *Max Heat* = "Overdrive Mode" (Invincible for 5s?).
*   **Close Call Bonus**: Grazing bullets restores Energy/Shield.

## Recommendation
We should start with **1. The "Juice" Update** immediately. It provides the highest ROI for "Game Feel". A game can have simple mechanics but still be addictive if the feedback loop is tight.
