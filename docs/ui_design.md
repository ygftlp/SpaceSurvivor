# 《星际幸存者》 UI/UX 设计方案 (Game Product Design)

本文档从产品角度重新梳理游戏的核心界面布局与交互流程，旨在打造“精品化、沉浸式”的科幻空战体验。

**核心设计原则:**
1.  **沉浸感 (Immersion)**: 尽可能减少 UI 遮挡，让玩家聚焦于战机与太空背景。
2.  **易用性 (Accessibility)**: 核心操作区集中在屏幕下半部分（单手舒适区）。
3.  **商业化融合 (Monetization)**: 在不打断心流的前提下，自然植入激励视频入口（如双倍奖励、复活）。

---

## 页面架构 (Page Structure)

基于微信小游戏的轻量化特点，建议将游戏划分为 **4 个核心的一级页面 (Scenes)**，其他功能作为 **弹窗 (Popups)** 依附于主页。

### 1. 启动页 (Loading Scene)
*   **功能**: 资源预加载、云端数据同步、用户登录 (OpenID 获取)、健康游戏公告。
*   **表现**: 品牌 Logo -> 进度条 -> "点击开始"。

### 2. 主界面 (Home Scene)
*   **定位**: 极简风格的展示大厅。
*   **核心元素**:
    *   **左上角**: **[个人中心]** 头像按钮。点击进入详细管理页面。
    *   **中央**: 战机 3D/2D 动态展示 (可旋转)。
    *   **底部**: 巨大的 **[开始战斗]** 按钮。
    *   *(移除原本拥挤的装备槽位，将其移至个人中心或保留为简略显示)*

### 3. 个人中心 (Profile Scene / Dashboard)
*   **定位**: 功能聚合页 (All-in-One Manager)。
*   **包含模块**:
    *   **账户 (Account)**: 名字、ID、头像、等级。
    *   **设置 (Settings)**: 音效、震动开关。
    *   **战机 (Fighter)**: 战机切换、预览。
    *   **装备 (Equipment)**: 详细的背包网格、装备拆装、强化。
*   **交互**: 采用侧边栏或顶部标签页 (Tabs) 切换不同模块。

### 4. 战斗界面 (Battle Scene)
*   **定位**: 核心玩法循环。
*   **功能**: 摇杆/触摸控制、敌人刷新、伤害判定、掉落渲染。
*   **弹窗**: 暂停菜单、复活倒计时 (看广告复活)。

### 4. 结算界面 (Result Scene)
*   **定位**: 战斗结束后的反馈与奖励派发。**这是商业化的核心节点**。
*   **功能**:
    *   显示本次得分、杀敌数。
    *   展示获得的战利品 (装备、金币)。
    *   **[看广告双倍领取]** 按钮。
    *   [返回主页] / [再次挑战]。

## 1. 游戏主界面 (Home / Hangar)

这是玩家进入游戏的第一印象，也是展示养成成果的核心场所。

**布局结构 (基于 720x1280):**

*   **顶部栏 (Top Bar) [Z-Index: 10]**
    *   `Top-Left`: **用户头像 & 等级** (点击查看个人信息/ID)。
    *   `Top-Right`: **资源监视器**。
        *   [💎 钻石] [+] (点击跳转商店)
        *   [💰 金币] [+]
        *   [⚡ 体力] [+] (若设计体力系统)
        *   [⚙️ 设置] (音效/震动开关)

*   **中央展示区 (Center Stage) [Z-Index: 1]**
    *   **背景**: 动态的太空机库背景，有星云流动或机械臂运作的一张图。
    *   **主角**: **3D/2D 高精渲染战机**，位于屏幕正中央略偏上。
        *   *交互*: 左右滑动可切换已拥有的战机（未来扩展）。
    *   **装备挂点 (Equipment Slots)**: 围绕战机的四个环形节点。
        *   `左上`: **主武器 (Main Gun)**
        *   `右上`: **僚机 (Wingman)**
        *   `左下`: **装甲 (Armor)**
        *   `右下`: **雷达/芯片 (Radar)**
        *   *交互*: 点击节点弹出“装备/升级”弹窗。

*   **底部操作区 (Bottom Command) [Z-Index: 10]**
    *   **战役按钮 (Start Button)**: 巨大的、呼吸发光的按钮，位于底部正中 (`y: 1000`)。
        *   显示文字: "出 击 (START)"
        *   显示消耗: "⚡ 5"
    *   **底部导航栏 (Bottom Nav)** (可选，未来扩展):
        *   [商城] - [天赋] - [**机库**] - [任务] - [排行]

## 2. 战斗界面 (Combat HUD)

战斗中保持极简，让视觉集中在弹幕回避上。

*   **顶部信息 (Top HUD)**
    *   `Top-Left`: **HP 条** (绿色长条) & **护盾条** (蓝色细条)。
    *   `Top-Center`: **波次进度 / Boss 血条**。
        *   显示: "Wave 1/5" 或 Boss 名称与血条。
    *   `Top-Right`: **暂停按钮 (||)** & **当前分数/金币**。

*   **游戏区 (Gameplay Area)**
    *   **战机**: 始终跟随手指（或相对移动）。
    *   **伤害数字**: 暴击显示为黄色/红色大字，普通伤害白色小字（可设置关闭）。

*   **底部相关 (Bottom)**
    *   **技能按钮** (如有): 屏幕右下角放置一个“必杀技/Bomb”按钮 (`CD` 冷却显示)。

---

## 3. 结算界面 (Result Screen)

高多巴胺反馈设计，利用音效和动效强调“获得感”。

*   **胜利/失败 (Victory/Defeat)**
    *   大标题动效轰出。
*   **星级评价**: ⭐️⭐️⭐️ (根据受击、时间或分数)。
*   **战利品列表 (Loot)**:
    *   横向滚动展示获得的金币、装备碎片。
*   **核心按钮组**:
    *   `左`: **[领取奖励]** (普通领取)。
    *   `右`: **[🎬 双倍领取]** (高亮推荐，看广告 x2)。
    *   `下`: **[再次挑战]** / **[返回机库]**。

---

## 4. 装备/升级弹窗 (Upgrade Popup)

覆盖在主页之上的半屏弹窗。

*   **左侧**: 装备图标 & 当前属性 (Lv.1 攻击力 +10)。
*   **右侧**: 升级预览 (Lv.2 攻击力 +12)。
*   **底部**:
    *   **[升级]** (消耗金币)。
    *   **[一键合成]** (如果有多余同名装备)。
    *   **[卸下/更换]**: 跳转背包网格选择新装备。

---

## 5. UI 技术实现建议 (Tech Stack)

*   **层级管理**:
    *   `GameLayer` (战场)
    *   `UILayer` (HUD)
    *   `PopupLayer` (弹窗、结算)
    *   `TopLayer` (Loading, Toast)
*   **资源规范**:
    *   所有 UI 按钮支持“按下缩放”效果 (Tween Scale)。
    *   统一字体 (建议使用开源游戏字体如 "Kenney Future" 或系统默认粗体)。
    *   统一色板:
        *   主题色: 科技蓝 `0x00A8FF`
        *   强调色: 警示红 `0xE84118` (HP/Enemy)
        *   奖励色: 黄金黄 `0xFBC531` (Gold/VIP)

这个设计方案旨在让《星际幸存者》脱离“Demo感”，向商业化成品靠拢。
