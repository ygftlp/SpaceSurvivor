# 星际幸存者 (Space Survivor)

> **"末日之后，你是人类最后的防线。"**

## 1. 为什么叫 "星际幸存者"？ (The Concept)
这不仅仅是一个射击游戏，这是一个**太空背景的 Roguelite 生存游戏**。
*   **星际 (Space)**: 地球沦陷后，人类驾驶改装的战机流亡宇宙。你驾驶的 F-22/J-20 不再是大气层战机，而是装备了核聚变引擎的**太空截击机**。
*   **幸存者 (Survivor)**: 玩法致敬《吸血鬼幸存者》。敌人是无穷无尽的异星虫潮，你不需要寻找出口，唯一的胜利条件就是——**活下来 (Survive)** 哪怕多一秒。

## 2. 核心玩法 (Gameplay Loop)
1.  **尸潮求生**: 面对成百上千的敌人包围，寻找缝隙生存。
2.  **无限进化**: 击杀敌人 -> 掉落蓝球（Bio-Energy） -> 升级战机。
3.  **Build 构建**:
    *   *Lv.1*: 发射普通子弹。
    *   *Lv.10*: 解锁这该死的**“全屏激光矩阵”**。
    *   *Lv.20*: 召唤僚机群，构建无人机防线。

## 3. 为什么是现代战机？ (Lore)
在流亡纪元，人类没有资源建造大型星舰。工程师们挖掘出旧时代的图纸，将**J-20 威龙**、**F-22 猛禽**等传奇战机进行**魔改**：
*   加装等离子护盾。
*   挂载反物质导弹。
*   这就是本作独特的**“硬核科幻复古”**美学。

## 4. 终极目标
保护母舰（Home）完成跃迁充能。倒计时结束时，你将面对异星母巢的主宰（BOSS）。击败它，为人类赢得前往下一个星系的门票。
