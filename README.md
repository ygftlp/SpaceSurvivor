# Space Survivor (星际幸存者)

## 游戏简介 (Introduction)
**Space Survivor** 是一款**硬核科幻风格的 Roguelite 空战游戏**。
玩家将驾驶 J-20、F-22 等高保真战机，在无尽的弹幕中生存，通过升级构建独特的技能组合，最终击败巨型母舰。

## 核心特色 (Key Features)

### 1. 真实战机 (High-Fidelity Fighters)
不同于传统的卡通飞机，我们提供精细建模的现代战机：
*   **J-20 威龙**: 隐身刺客，拥有“光学迷彩”能力。
*   **F-22 猛禽**: 空优霸主，矢量推力带来极致机动。
*   **Su-57 罪犯**: 格斗专家，配备等离子护盾。
*   **F-16 战隼**: 均衡型战机，适合新手。

### 2. Roguelite 技能构建 (Skill Build)
每次升级提供随机三选一技能：
*   **多重射击**: 增加弹道数量。
*   **僚机支援**: 召唤无人机协同作战。
*   **弹射装甲**: 受伤时释放冲击波。
*   ...以及更多组合！

### 3. 硬核视觉 (Hardcore Visuals)
*   **矢量喷口**: 动态的引擎尾焰效果。
*   **马赫环**: 加速时的视觉冲击。
*   **真实挂载**: 导弹、雷达、油箱均可见。

## 游戏目标 (Objective)
1.  **生存**: 躲避满屏弹幕。
2.  **成长**: 收集能量，升级技能。
3.  **征服**: 击败关卡 BOSS，解锁更强战机。
